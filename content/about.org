Hi, I'm Yi-Ping Pan (Cloudlet), a compiler engineer in Taiwan.

I'm a Staff Engineer at Kneron, working on an MLIR-based compiler for edge NPU accelerators. Before that I spent four years on the VHDL compiler in Synopsys VCS, mostly on compile-time performance. The fix I'm proudest of replaced a quadratic search with a direct lookup and cut one design's compile time by 98.9%.

I write here about how compilers and runtimes work inside. Good places to start:

- [[/technical/emacs/emacs-01/][Emacs Internals]] (4 parts): GNU Emacs as a Lisp runtime in C. Parts 2 and 3 reached the Hacker News front page.
- [[/technical/compiler/catching-nan-at-the-mlir-pass-boundary/][Catching NaN at the MLIR Pass Boundary]]
- [[/technical/refactor-with-ai/][Refactoring with AI]] (2 parts): deleting dead compiler code with an untrusted LLM, verified at both ends.

Outside work I build [[https://github.com/TheCloudlet/timeball][timeball]], a timing engine for hardware simulators, and [[https://github.com/TheCloudlet/Coogle][Coogle]], Hoogle-style type search for C++. I also rewrote the map in [[https://github.com/sysprog21/rv32emu/pull/144][rv32emu]], merged upstream.
